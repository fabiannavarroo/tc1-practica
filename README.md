# TC1 · Práctica de redes

Web estática en español para practicar las 33 preguntas de `PreguntasTC1.pdf`, aportado por el usuario (CAS_uc3m / Wuolah).

- Preguntas y opciones en orden aleatorio en cada sesión, sin repetir preguntas.
- Comprobación al responder, avance, salto y navegación por pregunta.
- Resultado final y repaso de errores o preguntas sin contestar.
- Diseño adaptable, uso con teclado y funcionamiento sin servicios externos.

La puntuación sigue literalmente la línea `Respuesta` de cada pregunta del PDF. Las preguntas 2, 9, 10, 23, 30 y 32 incluyen avisos por contradicciones o duplicados del documento. No se han inventado soluciones ni eliminado las preguntas similares 12 y 31. El PDF original no se publica en este repositorio.

## Uso

Abre `index.html` o sirve esta carpeta con cualquier servidor estático. No requiere instalación ni compilación. En GitHub Pages, publica desde la raíz de la rama `main`.

Los enunciados y las opciones están en `questions.js`, la interacción en `app.js` y el diseño en `styles.css`. El orden de las opciones se mezcla manteniendo su identificador original para corregir correctamente.
